# 物理实验曲线绘图工具 1.0

一个使用 Python、Tkinter、Matplotlib 和 NumPy 编写的桌面绘图工具，适合大学物理实验的数据处理、曲线对比和实验报告配图。

## 功能

- 同时绘制并对比多条曲线
- 自定义标题、坐标轴名称和单位
- 设置 X、Y 坐标轴显示范围
- 显示或隐藏网格、图例
- 调整数据的显示精度
- 自动生成等差数列和等比数列
- 插入常用物理符号和 LaTeX 公式
- 鼠标悬停查看数据点坐标
- 导出 PNG、JPG、PDF、SVG 图片

## 运行环境

- Python 3.8 或更高版本
- Windows 10/11
- Tkinter（Python 官方 Windows 安装包通常已自带）
- Matplotlib
- NumPy

## 安装

克隆或下载本仓库后，在项目目录中执行：

```bash
python -m pip install -r requirements.txt
```

## 运行

```bash
python 绘图工具1.0.py
```

## 数据格式

X 轴和 Y 轴数据使用英文逗号分隔，例如：

```text
1,2,3,4,5
```

每条 Y 轴数据的数量需要与 X 轴数据数量一致。

## 使用方法

1. 输入 X 轴数据。
2. 添加一条或多条 Y 轴曲线，并设置名称、颜色和线型。
3. 根据需要设置标题、坐标轴名称、单位、范围、网格和图例。
4. 点击绘图按钮生成曲线。
5. 使用导出功能保存图片。
